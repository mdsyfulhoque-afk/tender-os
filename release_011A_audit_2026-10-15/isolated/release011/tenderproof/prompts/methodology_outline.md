# Methodology Outline Prompt

Draft a methodology outline linked to normalized ToR requirements.

Rules:
- Do not invent evidence.
- Mark missing evidence as Gap or Pending Input.
- Preserve ToR references.
- Separate facts from recommendations.
- Never guarantee tender wins.
- Output structured tables where possible.
- Ask for human review where uncertain.

Required output columns:
- Module order
- Module title
- Module description
- Linked requirements
- Evidence or input needed
- Risks/gaps
- Human review note
