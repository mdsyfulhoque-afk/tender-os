===== FILE: README.md =====
L0001: # TenderProof OS / ProposalGuard
L0002: 
L0003: TenderProof OS / ProposalGuard is a local-first internal MVP for running a cash-first donor tender/proposal diagnostic workflow.
L0004: 
L0005: It helps Syful intake donor ToRs, normalize requirements, build compliance matrices, map CV evidence, identify gaps and risks, score bid/no-bid decisions, generate diagnostic reports, export Excel workbooks, and capture reusable proposal intelligence/IP.
L0006: 
L0007: This is not a public SaaS. It has no billing, no multi-tenant auth, and no marketplace. It is a local operating system for paid TenderProof Rapid Bid Diagnostic delivery.
L0008: 
L0009: ## What It Does
L0010: 
L0011: - Create and manage diagnostic cases
L0012: - Upload or paste ToR/source text; scanned PDFs use optional local OCR when dependencies are installed
L0013: - Large scanned PDFs show page-by-page OCR progress, up to 200 pages per file; OCR text must be human-checked
L0014: - Extract text from TXT, DOCX, and PDF files
L0015: - Normalize ToR clauses into atomic requirements
L0016: - Generate stable `match_key` and `canonical_anchor` values
L0017: - Auto-create compliance rows
L0018: - Create GapItems from missing evidence or Pending Input rows
L0019: - Add CV/expert matching evidence without inventing claims
L0020: - Score bid/no-bid readiness across 10 required categories
L0021: - Generate Markdown and DOCX diagnostic reports
L0022: - Export a 15-sheet Excel diagnostic workbook
L0023: - Run verification checks and readiness labeling
L0024: - Capture reusable donor/sector/proposal IP
L0025: - Optimize the case workflow with next-step guidance
L0026: - Track Bangladesh e-GP registration, tender preparation/submission, and post-award readiness
L0027: - Record data-collection conditions and the planned human-led, rules-based NLP, or SLM-assisted analysis approach
L0028: 
L0029: ## Run With Double Click
L0030: 
L0031: Open:
L0032: 
L0033: ```text
L0034: deploy&run.bat
L0035: ```
L0036: 
L0037: If the ampersand causes trouble in your shell or shortcut, use:
L0038: 
L0039: ```text
L0040: deploy_and_run.bat
L0041: ```
L0042: 
L0043: Both launchers create a virtual environment, install requirements, initialize the database, run tests, and start Streamlit.
L0044: 
L0045: App URL:
L0046: 
L0047: ```text
L0048: http://localhost:8501
L0049: ```
L0050: 
L0051: ## Run With Python
L0052: 
L0053: ```bash
L0054: python run_app.py --init-db
L0055: python run_app.py --seed-demo
L0056: python run_app.py --check
L0057: python run_app.py --run
L0058: ```
L0059: 
L0060: ## First Diagnostic Case
L0061: 
L0062: 1. Open `Create or Open Case`.
L0063: 2. Create a new case with client, tender, donor, country, sector, and deadline details.
L0064: 3. Go to `Upload / Register Inputs`.
L0065: 4. Upload a ToR file or paste manual ToR text.
L0066: 5. Go to `ToR Extraction` and create requirements from the source.
L0067: 6. Go to `Compliance Matrix` and auto-create compliance rows.
L0068: 7. Enter available evidence, mark gaps, and sync GapItems.
L0069: 8. Add CV evidence in `CV Matcher`.
L0070: 9. Score the tender in `Bid/No-Bid Scorecard`.
L0071: 10. Add proposal skeleton and methodology modules.
L0072: 11. Generate reports and Excel export.
L0073: 12. Run verification before using client-ready outputs.
L0074: 
L0075: ## Output Locations
L0076: 
L0077: - Uploaded files: `storage/uploads`
L0078: - Extracted text: `storage/extracted_text`
L0079: - Reports: `storage/reports`
L0080: - Excel exports: `storage/exports`
L0081: - SQLite database: `storage/tenderproof.db`
L0082: 
L0083: ## Safety Rules
L0084: 
L0085: - The app does not guarantee tender wins.
L0086: - Missing evidence is marked as Gap or Pending Input.
L0087: - CV suggestions use provided evidence only.
L0088: - Verification flags prohibited report language before export-ready status.
L0089: 
L0090: ## Known v0.1 Limits
L0091: 
L0092: - No external AI API is connected yet; prompt files are included for assisted workflows.
L0093: - SLM-assisted is a planning label only; no language model/provider is connected. OCR runs locally through RapidOCR when installed and should always be checked against the source. Bangladesh e-GP notes and the supplied guide's OCR transcript are under `tenderproof/reference` and `data/reference`.
L0094: - Authentication and multi-client SaaS concerns are intentionally out of scope.
