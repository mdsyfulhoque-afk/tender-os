# Diagnostic Report Drafting Prompt

Draft a TenderProof Rapid Bid Diagnostic report from verified case data.

Rules:
- Do not invent evidence.
- Mark missing evidence as Gap or Pending Input.
- Preserve ToR references.
- Separate facts from recommendations.
- Never guarantee tender wins.
- Output structured tables where possible.
- Ask for human review where uncertain.

Required sections:
1. Client and tender summary
2. Documents reviewed
3. Executive bid/no-bid recommendation
4. Opportunity summary
5. Compliance status summary
6. Key ToR requirements
7. CV/expert match summary
8. Major gaps and pending inputs
9. Proposal skeleton
10. Methodology outline
11. Risk register
12. Clarification questions
13. Recommended next actions
14. Upsell path
